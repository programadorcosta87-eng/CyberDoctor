# CyberDoctor

Plataforma educacional interativa para treinamento em Cibersegurança e Hacker Ético.

🔗 Acesse o projeto: https://seu-link-aqui.com

---

## 📋 Sobre o projeto

O **CyberDoctor** é uma plataforma educacional criada para proporcionar uma experiência prática de aprendizado em cibersegurança e hacking ético.

A proposta do projeto é transformar conceitos de segurança da informação em uma experiência mais interativa, utilizando laboratórios simulados, desafios, quizzes e um sistema de conquistas.

O ambiente foi pensado para que o usuário possa estudar conceitos relacionados à segurança digital sem realizar ataques contra sistemas reais.

---

## ✨ Funcionalidades

* Labs práticos de cibersegurança
* Quizzes interativos
* Biblioteca de conteúdo
* Sistema de conquistas
* Workspace isolado e simulado
* Ambiente 100% seguro para aprendizado
* Interface interativa e responsiva
* Sistema de acompanhamento da evolução do usuário
* Organização dos conteúdos por diferentes experiências de aprendizado

---

## 🎓 Proposta educacional

O projeto busca aproximar o aprendizado teórico da prática.

Em vez de apresentar somente textos sobre cibersegurança, o CyberDoctor organiza o conteúdo em uma experiência que envolve laboratórios, questionários, desafios e progressão.

A estrutura também foi pensada para facilitar futuras expansões, permitindo adicionar novos laboratórios, conteúdos, quizzes e desafios à plataforma.

---

## ⚠️ Aviso

Este é um ambiente 100% simulado e isolado. Nenhum ataque real é realizado. Ideal para estudo e prática ética.

Todas as atividades são destinadas ao aprendizado e à compreensão de conceitos de cibersegurança em um ambiente controlado.

## 🚀 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/programadorcosta87-eng/CyberDoctor.git
```

### 2. Entre na pasta

```bash
cd CyberDoctor
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o projeto

```bash
npm run dev
```

O projeto utiliza a porta `3000` em desenvolvimento.

Acesse:

```text
http://localhost:3000
```

## 📦 Build para produção

```bash
npm run build
```
